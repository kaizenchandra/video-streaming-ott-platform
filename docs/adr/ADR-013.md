# ADR-013: AWS deployment model

Status: Accepted technical baseline under autonomous task authority, 2026-10-08. Not external approval.

## Context

FR-037; NFR-001,012,014. Greenfield repository; workload targets are assumptions.

## Decision

Single AWS region across3AZ; EKS+managed owner stores/private origin.

## Alternatives

Single-AZ VMs; multi-cloud day1.

## Rationale

Multi-AZ matches availability without multi-cloud correctness overhead.

## Consequences

Cost/account approval before apply; local config not production evidence.

## Operational Impact

IRSA, probes, PDB/topology, IaC review and rollback.
