# ADR-012: Authentication provider

Status: Accepted technical baseline under autonomous task authority, 2026-10-08. Not external approval.

## Context

FR-001..003; NFR-006. Greenfield repository; workload targets are assumptions.

## Decision

OIDC provider (Keycloak locally), no platform passwords, issuer+subject identity.

## Alternatives

Custom password/JWT issuer; accept gateway identity headers.

## Rationale

Mature IdP handles login/MFA/recovery; API ownership still enforced locally.

## Consequences

JWKS/audience/time validation and PKCE client integration needed.

## Operational Impact

JWKS cache/rotation, provider outage test and local realm bootstrap.
