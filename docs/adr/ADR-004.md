# ADR-004: REST vs gRPC vs Kafka

Status: Accepted technical baseline under autonomous task authority, 2026-10-08. Not external approval.

## Context

FR-010..014,022,032; NFR-010,011. Greenfield repository; workload targets are assumptions.

## Decision

External/internal bounded REST; async Kafka; reserve Protobuf for justified RPC.

## Alternatives

gRPC all internal; synchronous fan-out chains.

## Rationale

No measured RPC encoding bottleneck; event fan-out separates availability.

## Consequences

Versioned OpenAPI and event contracts, no deep sync chains.

## Operational Impact

Deadlines per hop; schema compatibility gate.
