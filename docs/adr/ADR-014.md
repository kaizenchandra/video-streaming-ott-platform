# ADR-014: Multi-region strategy

Status: Accepted technical baseline under autonomous task authority, 2026-10-08. Not external approval.

## Context

FR-037; NFR-008. Greenfield repository; workload targets are assumptions.

## Decision

Evolutionary active/passive with fenced writers and timed restore drills.

## Alternatives

Active-active finance/session writes; DNS-only failover.

## Rationale

Conflict-free financial/concurrency state more valuable than premature geography.

## Consequences

Async regional RPO; old grants must expire before issuance.

## Operational Impact

Restore/reconcile/fence/failback runbook; targets NOT VALIDATED.
