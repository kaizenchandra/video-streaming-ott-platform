# ADR-010: Media packaging strategy

Status: Accepted technical baseline under autonomous task authority, 2026-10-08. Not external approval.

## Context

FR-017..019; NFR-003,014,015. Greenfield repository; workload targets are assumptions.

## Decision

Source/device/content-specific ABR; HLS+DASH reuse compatible CMAF fragments.

## Alternatives

Universal ladder; separate duplicated files for every protocol.

## Rationale

Bandwidth/storage cost and source quality vary widely.

## Consequences

Versioned profiles; HEVC/AV1 conditional licensing/device support.

## Operational Impact

QC segment/manifest/checksum before publish; workflow retries idempotent.
