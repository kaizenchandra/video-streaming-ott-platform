# ADR-002: Control plane vs media data plane

Status: Accepted technical baseline under autonomous task authority, 2026-10-08. Not external approval.

## Context

FR-012..019,027; NFR-002,003. Greenfield repository; workload targets are assumptions.

## Decision

Business APIs issue eligibility/grants; CDN+S3 serve all normal media.

## Alternatives

Proxy media through Spring; direct public S3.

## Rationale

Media bandwidth dwarfs API work and must use cache/origin distribution.

## Consequences

Private origin and segment-wide authorization required.

## Operational Impact

Monitor CDN/origin separately; never size API pods for streaming bytes.
