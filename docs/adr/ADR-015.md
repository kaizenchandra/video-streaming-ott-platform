# ADR-015: Recommendation evolution

Status: Accepted technical baseline under autonomous task authority, 2026-10-08. Not external approval.

## Context

FR-023,024; NFR-010,014. Greenfield repository; workload targets are assumptions.

## Decision

Deterministic popular/trending/genre/actor/history baseline, async signals.

## Alternatives

ML infrastructure immediately; synchronous inference in playback.

## Rationale

No training evidence or scale requires ML; baseline testable and independent.

## Consequences

Consent/age/territory filtering; fallback on outage.

## Operational Impact

Freshness and fallback metrics; add ML only after measured value.
