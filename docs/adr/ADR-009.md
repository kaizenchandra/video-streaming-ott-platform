# ADR-009: DRM abstraction

Status: Accepted technical baseline under autonomous task authority, 2026-10-08. Not external approval.

## Context

FR-015,016,018; NFR-006. Greenfield repository; workload targets are assumptions.

## Decision

Provider port for Widevine/FairPlay/PlayReady; mock local only.

## Alternatives

Build DRM crypto in-house; pretend clear media is protected.

## Rationale

Commercial key custody/certification outside available environment.

## Consequences

Mock cannot launch; offline revocation bounded by license expiry.

## Operational Impact

KMS/HSM provider custody, device-bound audit and secret rotation.
