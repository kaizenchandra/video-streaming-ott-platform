# ADR-007: Transactional outbox

Status: Accepted technical baseline under autonomous task authority, 2026-10-08. Not external approval.

## Context

FR-007..011,020,022; NFR-004,005. Greenfield repository; workload targets are assumptions.

## Decision

Owner state and outbox in local ACID, bounded relay with ack before mark.

## Alternatives

Dual-write DB/broker; distributed2PC.

## Rationale

Crash between commit/publish must not lose state integration.

## Consequences

Duplicate publication allowed and consumers idempotent.

## Operational Impact

Prune only confirmed rows; per-aggregate version; backlog alarm.
