# ADR-001: Microservice boundaries

Status: Accepted technical baseline under autonomous task authority, 2026-10-08. Not external approval.

## Context

FR-001..037; NFR-001,004,012. Greenfield repository; workload targets are assumptions.

## Decision

Nine capability owners, implemented sequentially; never one service per entity.

## Alternatives

One monolith; entity-per-service.

## Rationale

Group local transactions and scale/failure ownership while keeping operational count bounded.

## Consequences

Separate databases and contracts; deployment work grows with owner count.

## Operational Impact

Need per-owner migration, backup, SLO and on-call inventory.
