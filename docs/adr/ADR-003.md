# ADR-003: Java vs Go

Status: Accepted technical baseline under autonomous task authority, 2026-10-08. Not external approval.

## Context

FR-037; NFR-012,013. Greenfield repository; workload targets are assumptions.

## Decision

Java21+Spring MVC by default; no Go or WebFlux now.

## Alternatives

Go everywhere; WebFlux high traffic by assumption.

## Rationale

Blocking transactional DB and mature Spring security make MVC proportional.

## Consequences

Workers sandbox native FFmpeg; Go only with later measured network need.

## Operational Impact

JVM limits/pools/GC monitored; release21 toolchain.
