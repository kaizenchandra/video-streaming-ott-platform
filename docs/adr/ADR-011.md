# ADR-011: Search synchronization

Status: Accepted technical baseline under autonomous task authority, 2026-10-08. Not external approval.

## Context

FR-007,022,023; NFR-005,009. Greenfield repository; workload targets are assumptions.

## Decision

Catalog outbox→Kafka→version-guarded OpenSearch projection.

## Alternatives

Sync index within catalog DB transaction; direct DB sharing.

## Rationale

Search availability cannot block authoritative publishing/playback.

## Consequences

Eventual freshness; rebuild from snapshot+watermark.

## Operational Impact

Index lag SLI, external versions and DLQ replay.
