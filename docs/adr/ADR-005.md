# ADR-005: PostgreSQL vs NoSQL allocation

Status: Accepted technical baseline under autonomous task authority, 2026-10-08. Not external approval.

## Context

FR-001..013,020..022; NFR-004,009. Greenfield repository; workload targets are assumptions.

## Decision

PostgreSQL owned transactional stores; OpenSearch projection in phase7; defer DynamoDB.

## Alternatives

DynamoDB all state; shared relational schema.

## Rationale

Local ACID/idempotency/financial invariants and known query patterns matter first.

## Consequences

High-volume watch state may require later measured migration.

## Operational Impact

Pool/index/partition monitoring and PITR; no cross-owner SQL.
