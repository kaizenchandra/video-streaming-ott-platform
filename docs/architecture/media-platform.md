# Media platform

Intake creates scoped presigned S3 multipart upload to private quarantine prefix; explicit size, checksum, content type and expiration. Callback verifies HEAD size/checksum before workflow start. Reject arbitrary URL ingestion (SSRF) and path traversal. Job key `(contentId,sourceVersion)` prevents duplicate jobs. Temporal workflow ID uses that key; activities idempotent via deterministic output prefixes and checksums.

Workflow: upload-complete→validate→FFprobe→source-specific ladder→FFmpeg transcode→HLS/DASH/CMAF package→DRM packager boundary→QC→S3 versioned origin→media.ready outbox. Failed stages retain resumable status; no catalog publication until validated ready event. Timeouts: probe30s; activity transcode bounded by duration/job budget; retry only transient infrastructure errors max3 with jitter; invalid sources permanent failure. Workers isolated CPU/memory/job concurrency, network allowlist, non-root, read-only filesystem+bounded scratch. Native media parsers run outside business HTTP process.

Profiles select renditions ≤source dimensions, codec/device capability, content class, bitrate/quality targets and cost. Baseline H264+AAC; HEVC only for supported premium devices with licensing/cost review; AV1 only where device support/encoding cost warrants it. Sports uses higher frame-rate motion profile; animation/talking head lower bitrate. Never upsample all content to a universal ladder. Configuration version becomes asset version metadata.

CMAF fMP4 fragments reused for HLS and DASH where encryption/codec compatibility allows. Multiple audio locales, captions WebVTT/TTML, audio description, forced subtitles and thumbnails tracked in manifest metadata. QC checks all playlists/MPDs, segment existence/checksums, duration and discontinuity, audio alignment, independent decodability, key-ID references, accessibility tracks and ABR ordering. Immutable versioned prefixes permit cache-safe deployment and rollback.

Deterministic fixture: FFmpeg lavfi testsrc2 plus sine, 8s 320x180@24fps; generate two supported non-upscaled renditions when source allows; FFprobe durations/streams; verify HLS segment paths and DASH init/media referenced files. No commercial keys/feed needed. Local clear mock packaging is labeled unprotected. Workflow DB and S3 side effects are not a 2PC: immutable writes, completion manifest, orphan cleanup and repeatable activity reconcile.

S3 encrypt with KMS, private buckets, lifecycle incomplete multipart7d/quarantine7d/source configurable90d; origin assets remain until rights/retention approved deletion. CDN serves bytes directly. Origin deletion first unpublishes metadata and waits max cache TTL; legal takedown uses purge/denylist procedure. Temporal snapshots/version markers preserve running workflow compatibility during rollout.


Initial implementation (phase5): PostgreSQL job upload/dispatch/processing/ready/failed; bounded single-PUT256MiB (multipart target not implemented yet), signed exact checksum/size/key/conditional-create, actual S3 HEAD verification and local SHA256 check before parsing. Stable Temporal job IDs with reject-duplicate policy; lost workflow-start responses reconcile AlreadyStarted. S3 conditional creates validate matching object hashes on retries; `_complete.json` last, then READY/outbox ACID. Transient activity retry maximum3, invalid source nonretryable; separate failed activity records safe code. Exhausted jobs require inspected new asset version.

Initial codec profile is H264/AAC with source-sized configured renditions. VOD max30fps, SPORT max60fps and configurable higher bitrate multiplier; profile part of job fingerprint and immutable completion metadata. All source audio tracks and text captions extracted, language metadata preserved; WebVTT in HLS/DASH plus thumbnail. MP4 only initially. QC checks all HLS file references, parses safe MPD, compares decoded playlist durations and sample-decodes first4s of every rendition. This does not claim exhaustive perceptual/DRM/long-form quality certification. Actual workflow tested through real Temporal development server, PostgreSQL, FFmpeg7.1 and S3-compatible emulator; clear output labeled MOCK_CLEAR_ONLY and production profile rejects the mock packager.

Local S3 emulator is LocalStack4.3.0 after official MinIO images could not be retrieved. Temporal CLI1.9.1/server1.32.0 pinned by verified digest; development server is not a production workflow persistence deployment. Sources for integration boundaries: [Temporal Java guide](https://docs.temporal.io/develop/java), [AWS presigned upload guide](https://docs.aws.amazon.com/sdk-for-java/latest/developer-guide/examples-s3-presign.html).


Recovery correction: native encoders are not assumed byte deterministic across retries. After QC, an atomic create-only validated ZIP is stored under a private staging job key before any origin publication. Retries load those original bytes, safely extract bounded filenames/≤1GiB total, validate every manifest checksum/source/config/profile, and conditionally publish the same objects. `_complete.json` is written last; READY/outbox remains one PostgreSQL transaction. An actual lost-publication-acknowledgement test failed under regeneration and passed after this correction. Jobs pin the canonical encoding-config SHA256; changed configuration requires a matching worker or a forward asset version.

V1 remains unchanged; V2 adds VOD/SPORT profile, V3 pins encoding configuration hash with a legacy baseline default. Native subprocesses execute fixed binaries/argument arrays and receive an allowlist environment excluding application credentials. Tools run directly; timeout terminates/waits for the direct native process. No shell or external process wrapper is supported in production. Standalone worker uses headless Spring, non-root10001, read-only root, bounded scratch/resources and no extra capabilities. Local image Linux amd64 requires emulation on this ARM host; no performance claim. Native parser exploit isolation/least-privilege IAM and full container scan remain launch work.
