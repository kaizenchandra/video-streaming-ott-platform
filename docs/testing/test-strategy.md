# Testing strategy

Each phase gate compiles→focused unit→real integration→API/contracts→quality→broader verification. Test results PASS/FAIL/NOT RUN separately; lack of Docker cannot become silently skipped passing integration. Unit JUnit5/Mockito names method_condition_expected. Java21 release enforced. No H2 substitute proves PostgreSQL locks/migrations; Testcontainers PG/Redis/Kafka/OpenSearch cover actual semantics.

Phase0: build, architecture inventories, OpenAPI parse/validate, Avro/proto compile, JWT signature/audience negatives, probes and Problem Details, local container health, real PG migration/rollback and Kafka/Redis round-trip foundation tests. Phase1: account identity race/ownership, kids restriction changes, device cap/revoke and concurrent registration real PG. Phase2: rights `[start,end)` boundary/country, publish state/version/events. Phase3: webhook signature, amount/currency mismatch, duplicate/collision/out-of-order, timeout unknown/reconcile, crash rollback/inbox/outbox. Phase4: multi-client acquire beyond cap real Redis/PG, heartbeats/expiry/release, Redis loss quarantine, unavailable eligibility, token/signature/DRM expiry. Phase5: real Temporal and deterministic synthetic FFmpeg media; retries/resume, corrupt upload, manifest/segment QA.

Phase6: duplicates/sequence/epoch/rewind/multi-device CAS; phase7: real outbox→Kafka→OpenSearch external version replay and search filters; phase8: deterministic recommendations/fallback; phase9: event transitions/start race/rights; phase10: cap race/duplicate ad metrics/ad-provider outage; phase11: prefs/send race/retry/DLQ; phase12: telemetry validation/dup/drop and assignment determinism; phase13: scopes/support/audit immutability; phase14: Helm lint/Terraform validate/container scans; phase15: E2E/load/chaos/security/SBOM; phase16: actual restore/failover evidence.

E2E extend Register@IdP→Authenticate→Account→Profile→Catalog→Order→Verified payment→Entitlement→Playback→Progress→Resume. Contract drift test validates runtime responses against OpenAPI and produced event schema. k6 realistic arrival rate, hot live event, steady/watch heartbeats; record version/hardware/data/latency/error and avoid scale extrapolation claims. Chaos isolated test environment only, never unsolicited production fault injection. Reconciliation tests compare source ledgers after recovery.


## Local release evidence

`-Pintegration,recovery,sbom verify` combines compile, Checkstyle, unit/real Testcontainers integration, OpenAPI/Avro compatibility, the complete nine-owner native-media business journey and independent restore checks. [Recovery runbook](../operations/recovery-runbook.md) explains quiescence and archived state. `scripts/deployment_check.py` verifies rendered deployment semantics/edge routes and production rejection cases; Terraform mock plans validate configuration without AWS calls. `scripts/container-drill.py`, `worker-container-drill.py` and `kubernetes-drill.py` run explicit disposable lifecycle/outage tests; only the first invokes the short authenticated account-read k6 scenario. Raw reports and ignored artifacts are evidence for the exact local environment. Remote CI, sustained load/SLOs, cloud/region/managed-service fault injection and commercial certification are separate NOT RUN gates.
