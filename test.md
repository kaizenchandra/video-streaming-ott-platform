# Test the OTT backend with curl

Run commands from the repository root in **one Bash session**, in section order. These examples target the localhost development runtime described in [README.md](README.md) and [local-runtime.md](docs/operations/local-runtime.md). They create new synthetic accounts, catalog items, plans and support records; they do not delete existing data. Payment and DRM providers are explicitly local mocks. Notifications below use IN_APP only.

The main walkthrough is curl-only and uses temporary **local test clients**, one unprivileged viewer, another viewer for ownership checks, and a scoped operator. This tests backend behavior, not human signup. [Human login and parental controls](#human-login-and-parental-controls-pkce) separately exercise the real public PKCE client. Password grants are disabled for `ott-viewer`; do not enable them to make a curl example work.

## 2. Private test files and local authentication

Keep credentials, signed URLs and playback responses in ignored private files. Do not use `set -x`, `curl -v`, `cat` token files, or put real credentials into this Markdown. The examples pass bearer headers, client secrets and signed requests through files rather than command arguments. `--fail` is used for successful calls; expected negative tests deliberately omit it so their response bodies remain inspectable.

This reusable function contains the real curl upload/workflow/publication calls. It saves each content's artifacts separately, allowing the optional SPORT test to reuse the same bounded source. HTTP publication waits for actual `media.ready.v1` processing; it does not inject readiness into a database.

```bash
publish_asset() {
  local content="$1" encoding="$2" folder="$TEST_DIR/asset-$1"
  mkdir -p "$folder"
  python3 - "$content" "$encoding" "$folder" <<'PY'
import hashlib,json,os,sys
from pathlib import Path
source=(Path(os.environ['TEST_DIR'])/'source.mp4').read_bytes()
Path(sys.argv[3]+'/upload-request.json').write_text(json.dumps({'contentId':sys.argv[1],'assetVersion':1,'bytes':len(source),'sha256':hashlib.sha256(source).hexdigest(),'encodingProfile':sys.argv[2]}))
PY
  refresh_test_token operator
  curl -fsS -H @"$TEST_DIR/operator.headers" --json @"$folder/upload-request.json" "$MEDIA/v1/admin/media/uploads" -o "$folder/intake.json"
  python3 - "$folder" <<'PY'
import json,sys,urllib.parse
from pathlib import Path
p=Path(sys.argv[1]);u=json.loads((p/'intake.json').read_text())['upload'];uri=urllib.parse.urlparse(u['url'])
assert uri.scheme=='http' and uri.hostname=='localhost' and uri.port==4566, 'Only local emulator uploads allowed'
lines=['url = '+json.dumps(u['url'])]
for key,values in u['headers'].items():
 assert '\n' not in key and '\r' not in key and '\n' not in values[0] and '\r' not in values[0]
 lines.append('header = '+json.dumps(key+': '+values[0]))
(p/'upload.curl').write_text('\n'.join(lines)+'\n')
PY
  # The S3 upload has its own signed headers; do not send an API bearer to S3.
  curl -fsS --max-time 60 --config "$folder/upload.curl" -X PUT --data-binary @"$TEST_DIR/source.mp4" -o /dev/null
  local job
  job=$(jq -er .job.id "$folder/intake.json")
  curl -fsS -H @"$TEST_DIR/operator.headers" --json '{}' "$MEDIA/v1/admin/media/jobs/$job/upload-completed" -o "$folder/job.json"
  for attempt in $(seq 1 120); do
    curl -fsS -H @"$TEST_DIR/operator.headers" "$MEDIA/v1/admin/media/jobs/$job" -o "$folder/job.json"
    state=$(jq -r .state "$folder/job.json")
    if [ "$state" = READY ]; then break; fi
    if [ "$state" = FAILED ]; then jq '{state,failureCode}' "$folder/job.json"; return 1; fi
    sleep 1
  done
  jq -e '.state=="READY"' "$folder/job.json" > /dev/null
  # Fetch this unpublished item's current revision via the stored creation/update response.
  jq '{version,locale:"en"}' "$folder/catalog.json" > "$folder/review.json"
  curl -fsS -H @"$TEST_DIR/operator.headers" --json @"$folder/review.json" "$CONTENT/v1/admin/catalog/$content/review" -o "$folder/catalog.json"
  jq '{version,assetVersion:1,locale:"en"}' "$folder/catalog.json" > "$folder/publish.json"
  for attempt in $(seq 1 30); do
    code=$(curl -sS --max-time 10 -w '%{http_code}' -H @"$TEST_DIR/operator.headers" \
      --json @"$folder/publish.json" "$CONTENT/v1/admin/catalog/$content/publish" -o "$folder/published.json")
    if [ "$code" = 200 ]; then break; fi
    if [ "$code" != 409 ] || ! jq -e '.code=="MEDIA_NOT_READY"' "$folder/published.json" > /dev/null; then
      jq . "$folder/published.json"; return 1
    fi
    sleep 1
  done
  jq -e '.state=="PUBLISHED"' "$folder/published.json" > /dev/null
  jq '{id,state,version}' "$folder/published.json"
}
mkdir -p "$TEST_DIR/asset-$CONTENT_ID"
cp "$TEST_DIR/catalog.json" "$TEST_DIR/asset-$CONTENT_ID/catalog.json"
publish_asset "$CONTENT_ID" VOD
```

## 6. Playback, heartbeat, limits and offline authorization

A plain country header is insufficient. The trusted-edge assertion binds issuer, subject, device and country; it is HMAC-SHA256 over `timestamp\nissuer\nsubject\ndevice\ncountry`, with a 30-second freshness window. Generate it immediately before each request using **only the local fixture key**. Production clients never receive that key.

```bash
cat > "$TEST_DIR/geo.py" <<'PY'
import base64,hashlib,hmac,json,os,sys,time
from pathlib import Path
p=Path(os.environ['TEST_DIR']);raw=json.loads((p/'viewer-token.json').read_text())['access_token']
c=json.loads(base64.urlsafe_b64decode(raw.split('.')[1]+'=='))
```
